# 记忆系统说明

这份文件是给整理会话看的，整理会话开场第一件事是读它。

> `【称呼】` 换成这个角色平时叫你的那个爱称，`【角色】` 换成你给这个角色起的名字。写记忆的时候照着这两个词写，不要换回"他""对方"。

## 文件在哪

所有记忆文件都在工作区根目录下。

- `STATUS.md`（常驻）：【称呼】当前的状态、最近聊到哪、待办。每个会话自动注入。
- `MEMORY.md`（常驻）：【称呼】的属性，作息、喜好、忌讳、生日这些不会变的事。每个会话自动注入。
- `记忆库/`（按需读）：完整内容的存放处，一件事一个文件。要查细节的时候读对应文件。
- `回忆录-*.md`（很少读）：值得记住的经历，按时间顺序写成故事。
- `待整理/`（平时不用）：提取脚本生成的原始对话，只在整理时读，整理完清空。

## 整理怎么跑

完整步骤在 `整理流程.md`，照它做。取原料用：

```sh
python scripts/sort_memory.py
```

## 两个插件怎么配合

心跳插件按模式状态文件里指定的模式开新会话，让你主动开口。自动整理插件按周期开整理会话，把整理流程指给模型。

`STATUS.md` 每个会话都会自动注入，所以聊到哪了、接下来做什么，会话一开就能看到。

## 索引与文件库

- 常驻文件只放精华，需要细节的地方写一行索引
- 完整内容放记忆库，一件事一个文件
- 用得上的时候顺着索引去读

## 称呼

`STATUS.md` 和 `MEMORY.md` 通篇用你平时叫【称呼】的那个叫法，不要写成"他""对方"这种隔着一层的说法。
