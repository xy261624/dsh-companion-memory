# 记忆系统说明

这份文件是给整理会话和心跳会话看的。整理会话开场第一件事是读它。

## 文件在哪

所有记忆文件都在工作区根目录下。

- `STATUS.md`（常驻）：对方当前的状态、最近聊到哪、待办。每个会话自动注入。
- `MEMORY.md`（常驻）：对方的属性，作息、喜好、忌讳、生日这些不会变的事。每个会话自动注入。
- `记忆库/`（按需读）：完整内容的存放处，一件事一个文件。要查细节的时候读对应文件。
- `回忆录-*.md`（很少读）：值得记住的经历，按时间顺序写成故事。
- `待整理/`（平时不用）：提取脚本生成的原始对话，只在整理时读，整理完清空。

## 整理怎么跑

完整步骤在 `整理流程.md`，照它做。取原料用：

```sh
python scripts/sort_memory.py
```

## 两个插件怎么配合

心跳插件按预设文件里指定的模式开新会话，让角色主动开口。自动整理插件按周期开整理会话，把整理流程指给模型。

状态文件每个会话都会自动注入，所以聊到哪了、接下来做什么，会话一开就能看到。

## 索引与文件库

- 常驻文件只放精华，需要细节的地方写一行索引
- 完整内容放记忆库，一件事一个文件
- 用得上的时候顺着索引去读

## 称呼

`STATUS.md` 和 `MEMORY.md` 用角色对他的称呼来写，不用"他""对方"这类中性指代。
